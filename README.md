# Am_stat - Статистика турниров

Система управления турнирами с аутентификацией через Telegram ID.

## Особенности аутентификации

Система поддерживает аутентификацию пользователей через Telegram ID с возможностью создания пароля для дополнительной защиты.

### Процесс аутентификации

#### 1. Первый вход пользователя

Когда пользователь впервые входит в систему используя свой Telegram ID:

1. **Ввод Telegram ID**: Пользователь вводит свой Telegram ID на странице входа
2. **Автоматический вход**: Если пользователь найден в базе данных и у него нет установленного пароля, он автоматически входит в систему
3. **Создание пароля**: Пользователь перенаправляется на страницу создания пароля (`/create-password/`)
4. **Установка пароля**: Пользователь должен создать пароль, соответствующий требованиям безопасности

#### 2. Последующие входы

После создания пароля пользователь должен входить используя:
- **Telegram ID** (или username)
- **Пароль**

### Требования к паролю

Для обеспечения безопасности установлены следующие требования:

- **Минимальная длина**: 8 символов
- **Подтверждение**: Пароль должен быть введен дважды для подтверждения
- **Хэширование**: Пароли хранятся в базе данных в зашифрованном виде с использованием встроенных механизмов Django (PBKDF2 с SHA256)

### Защита от перебора паролей

Реализована защита от brute-force атак:

- **Максимальное количество попыток**: 5 неудачных попыток входа
- **Блокировка**: После 5 неудачных попыток аккаунт блокируется на 15 минут
- **Счетчик попыток**: При каждой неудачной попытке пользователь видит количество оставшихся попыток
- **Автоматическая разблокировка**: Через 15 минут блокировка снимается автоматически

### Структура базы данных

#### Модель User (users/models.py)

```python
class User(AbstractUser):
    telegram_id = models.CharField(max_length=32, unique=True, editable=False)
    nickname = models.CharField(max_length=50)
    gender = models.CharField(max_length=10, choices=[('male', 'Муж'), ('female', 'Жен')])
    phone = models.CharField(max_length=20, blank=True)
    level = models.CharField(max_length=20, blank=True, editable=False)
    photo = models.ImageField(upload_to='profiles/', blank=True, null=True)
    rating = models.DecimalField(max_digits=4, decimal_places=2, default=0.00)
    # password - наследуется от AbstractUser
```

Поле `password` наследуется от Django's `AbstractUser` и используется для хранения хэша пароля.

### Реализованные компоненты

#### 1. Backend аутентификации (users/auth.py)

`TelegramBackend` - кастомный backend аутентификации, который:
- Поддерживает вход по Telegram ID или username
- Проверяет наличие пароля у пользователя
- Валидирует пароль если он установлен
- Позволяет вход без пароля если пароль не установлен (только для первого входа)

#### 2. Формы (users/forms.py)

**TelegramLoginForm** - форма входа:
- Поля: `telegram_id`, `telegram_username`, `password`
- Валидация: требует хотя бы один идентификатор (ID или username)

**PasswordCreationForm** - форма создания пароля:
- Поля: `password1`, `password2`
- Валидация: минимум 8 символов, пароли должны совпадать

#### 3. Views (users/views.py)

**TelegramLoginView** - обработка входа:
- Проверка защиты от brute-force
- Определение наличия пользователя в базе
- Проверка наличия пароля у пользователя
- Редирект на создание пароля для новых пользователей
- Аутентификация с паролем для существующих пользователей

**create_password** - создание пароля для первого входа:
- Доступно только аутентифицированным пользователям без пароля
- Валидация требований к паролю
- Установка пароля и сохранение сессии

**set_password** - изменение пароля:
- Доступно из профиля пользователя
- Валидация требований к паролю

**profile_view** - профиль пользователя:
- Просмотр и редактирование профиля
- Изменение пароля

#### 4. URLs (users/urls.py)

```python
/login/             - Вход в систему
/create-password/   - Создание пароля (первый вход)
/set-password/      - Изменение пароля
/profile/           - Профиль пользователя
/logout/            - Выход
```

#### 5. Шаблоны (templates/registration/)

- `login.html` - страница входа
- `create_password.html` - страница создания пароля для новых пользователей
- `set_password.html` - страница изменения пароля

### Безопасность

1. **Хэширование паролей**: Используется встроенный механизм Django (PBKDF2 с SHA256)
2. **CSRF защита**: Все формы защищены CSRF токенами
3. **Защита от brute-force**: Ограничение попыток входа
4. **Требования к сложности пароля**: Минимум 8 символов
5. **Защита сессий**: Автоматическое обновление хэша сессии при изменении пароля
6. **Уникальность Telegram ID**: Предотвращает дублирование учетных записей

### Примеры использования

#### Вход для нового пользователя:
1. Пользователь переходит на `/login/`
2. Вводит свой Telegram ID: `123456789`
3. Система находит пользователя, входит и перенаправляет на `/create-password/`
4. Пользователь создает пароль (минимум 8 символов)
5. Система сохраняет хэш пароля и перенаправляет на `/profile/`

#### Вход для существующего пользователя:
1. Пользователь переходит на `/login/`
2. Вводит Telegram ID: `123456789` и пароль
3. Система аутентифицирует и перенаправляет на `/profile/`

#### Защита от brute-force:
1. Пользователь вводит неверный пароль 5 раз
2. Система блокирует попытки входа на 15 минут
3. Пользователь видит сообщение: "Слишком много попыток входа. Попробуйте через X минут"
4. Через 15 минут блокировка снимается автоматически

### Логика работы в коде

#### 1. Проверка пользователя при входе (views.py):
```python

user = User.objects.filter(telegram_id=telegram_id).first()

# Проверка наличия пароля
if not user.has_usable_password():
    # Первый вход - редирект на создание пароля
    return redirect("create_password")
else:
    # Обычный вход с проверкой пароля
    user_auth = authenticate(...)
```

#### 2. Защита от brute-force (views.py):
```python
def _check_brute_force(self, request, identifier):
    session_key = f"login_attempts_{identifier}"
    attempts = request.session.get(session_key, 0)
    
    if attempts >= self.max_attempts:
        # Блокировка на 15 минут
        lockout_until = timezone.now() + timedelta(minutes=15)
        ...
```

#### 3. Создание пароля (views.py):
```python
def create_password(request):
    if request.method == "POST":
        password = form.cleaned_data.get("password1")
        user.set_password(password)  # Автоматическое хэширование
        user.save()
        update_session_auth_hash(request, user)  # Сохранение сессии
```
